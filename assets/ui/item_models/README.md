# Alchemy item models

## Shipping art: `pixel_art_v1/`

The current Bag, workbench, and Chemistry evidence views use the 13 GPT-generated PNGs in `pixel_art_v1/`: two text-free formula sheets, two herbs, three reagents, three potions, and three red-stain trace samples. They were generated for this repository on 2026-08-14 with the project's dark-brass, violet, parchment, and pixel-art art direction.

The art contains no functional copy. Item names, quantities, requirements, and puzzle feedback remain Godot UI text. Each source PNG includes alpha and is imported by Godot as a UI texture.

## Historical prototypes

The sibling SVG files are earlier code-authored prototypes retained only for process provenance and safe rollback. They are no longer active item-art references.
