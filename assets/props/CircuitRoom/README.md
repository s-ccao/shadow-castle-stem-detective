# Circuit Room switch models

`switch_auxiliary.svg`, `switch_regulator.svg`, and `switch_master.svg` were authored for this repository on 2026-08-14 as text-free dark-brass switch hardware.

The room and repair map both read positions and dimensions from `scripts/circuit_layout.gd`; the map does not maintain independent marker coordinates. Functional sequence numbers remain code-native labels so localization and accessibility do not depend on baked text.
