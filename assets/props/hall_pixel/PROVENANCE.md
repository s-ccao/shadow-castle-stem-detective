# Hall prop pixel pass — provenance

Created 2026-10-21 by GitHub Copilot for the Castle Hall prop readability fix
(the props read as aliased "stickers" at gameplay zoom).

## What these files are

Processed derivatives of the project's **existing AI-generated Hall prop
images**. Nothing here is a new image generation, external image or hand
repaint: `tools/pixelize_hall_props.gd` (Godot `Image` API, offline) rebuilds
every output deterministically from the unchanged sources listed below. The
sources stay in place; `dining_grandfather_clock.png` is still used by the
Dining Hall room scene. The source images' rights and restrictions continue to
apply. Per-asset parameters, palettes, hashes and layout data are in
[`manifest.json`](manifest.json).

## Pipeline

1. **Backdrop removal.** Every source is scanned per side for a run of
   ≥ 90 % near-black lines (plus one neutral frame line on the outer ring) at
   least 16 px thick. Only `final_key_machine_1.png` has one: a 25 px opaque
   box on its right edge (54 % of its border was opaque). That margin is flood
   filled from the border and specks under 300 px are dropped (32,462 px).
2. **White-remnant removal.** Enclosed neutral white regions (all channels
   ≥ 228, ≥ 40 px) left from the generator's paper background between pipes,
   leaves and frames are cleared with their light fringe when surrounded by
   dark art. White glow cores inside bright coloured light are kept.
3. **Crop** to the object's opaque bounds.
4. **Downsample** by exact area averaging in linear light with premultiplied
   alpha (no nearest sampling of the big source). Texel size equals the
   displayed world size / 1.25, so each texel is 1.25 world px like the Hall
   walls/floor; anchored at the object's bottom centre.
5. **Binary alpha** at 0.5 coverage.
6. **Clarity:** gentle OKLab lightness unsharp mask (3×3, opaque neighbours
   only) plus light 7×7 local contrast. Greenhouse foliage uses half strength
   because it is already high-frequency.
7. **Harmonisation** with the UI's dark brass, violet and parchment: 1.1 chroma
   gain; near-neutral shadows lean to `#33243d`, near-neutral highlights to
   `#ead9b3`, blacks lift toward `#140c18`. Saturated glows, foliage and gauge
   blues keep their hue. The chemistry core gets a mid-tone lift and extra
   chroma so its brass stays readable.
8. **Selective 1 px outline:** silhouette pixels take a darker shade of the
   adjacent interior colour, anchored at `#140c18` and darkest on the two base
   rows. This separates props from the dark floor.
9. **Palette:** deterministic median cut followed by k-means in hue-weighted
   OKLab, built from the harmonised source pixels. Pixels map to their nearest
   entry without dithering. Isolated low-contrast single pixels merge into
   their neighbours, while high-contrast rivets and glints stay.

`hall_contact_shadow.png` is an atlas of eight dithered ellipses (16×6 up to
120×12) in `#140c18` at 60 % alpha: a solid core with a 50 % checkerboard edge.
Each prop uses the ellipse that fits its base, selected with `region_rect`.

## Integration (`scenes/wall_collisions.tscn`)

- The nine prop `Sprite2D`s use these textures with uniform scale `1.25`,
  `texture_filter = 1` (nearest) and their original `centered` mode. Parent
  nodes, collision shapes and interaction areas are unchanged.
- Positions keep the world bottom centre of the visible object (the
  `RoomSpatialRuntime.get_visual_feet()` anchor) within 0.8 px. Top-left
  corners sit on the walls' 1.25 px texel lattice.
- Each prop sprite has a `ContactShadow` child sprite with
  `show_behind_parent = true`. It is a grandchild of the exhibit node, so the
  exhibit's first `Sprite2D` child is still the prop sprite.
- Import settings: lossless (`compress/mode=0`) and no mipmaps.

## Rebuild

```bash
mkdir -p .godot/hall-props-home
HOME="$PWD/.godot/hall-props-home" <godot> --headless --path . \
  --script res://tools/pixelize_hall_props.gd -- --contact-sheet
HOME="$PWD/.godot/hall-props-home" <godot> --headless --editor --path . --quit
```

The script prints the `Sprite2D` position and `ContactShadow` values for each
prop. If the sources or the authored layout change, apply those values to the
scene. Evidence: `docs/evidence/2026-10-21-hall-visual/props/`.
